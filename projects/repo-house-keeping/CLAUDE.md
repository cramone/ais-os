# Repo House Keeping

Repo migration from infoxpert ADO, magiq.visualstudio.com ADO, MAGIQSoftware ADO and GitHub into the `springbrooksoftware` GitHub Enterprise.
Full role, schema, triage rules and phases come from the project instructions (source: `PROMPT.md`). Don't re-read PROMPT.md unless editing it.

**Status:** Phase 1 — Inventory (started 2026-10-01) · **Priority:** Medium · **ADO Board:** not assigned

## Team
- Chase Ramone — lead
- Karen Barton — advisory only; no repo/enterprise access at this stage (no seat)

## Standing rules
- All repos created in the springbrooksoftware enterprise **must be prefixed `mgq-`** (e.g. `mgq-media`). See decisions/log.md D-001.

## Access model
- Claude's sandbox **can't reach** ADO or GitHub (network allowlist). Chase runs the scripts locally, and Claude reads the output in `spec/inventory/`.
- The ADO connector covers **dev.azure.com/MAGIQSoftware only**.
- Secrets live in `.env` (gitignored; template is `.env.example`). Never print or read out its values.

## File Map (read on demand only)

| File | Purpose |
|------|---------|
| spec/repo-register.csv | Source of truth for every repo — read when a task touches repos |
| start-dashboard.bat | Double-click: starts `scripts/serve_dashboard.py` (http://localhost:8765) and opens the live dashboard. Edits auto-save to `spec/repo-register.csv` / `spec/tasks.csv`; old versions go to `spec/.backups/`. If the server is running, don't hand-edit those CSVs mid-save; the dashboard picks up file changes within ~3s |
| dashboard.html | Static offline snapshot (generated by `python scripts/build_dashboard.py`). Edits queue in-browser; export CSV/diff to apply |
| spec/notes/<source>.md | Ad-hoc working notes per source (edited in the dashboard's Source notes tab; Claude may read them for context) |
| spec/tasks.csv | Work queue (owner Chase/Claude) shown in dashboard Work Queue tab |
| spec/package-dependencies.csv | Per-package consumer tracking for held library repos |
| archive/ | Local cold-storage mirrors/zips of held repos (see archive/README.md). Folders are created/deleted from the dashboard drawer (**Archive location**); the `rhk:status` block in each `ARCHIVE.md` and the index in `archive/README.md` are dashboard-managed, so write notes outside those markers |
| scripts/ | `inventory_ado.py` (catalog an org into `spec/inventory/`), `archive-ado-repo.sh`, `lib/env.sh` |
| spec/inventory/<source>/<date>/ | Raw inventory output. Merged into the register after review |
| brief.md | Background, integrations, scope detail |
| decisions/log.md | Decisions (append-only) |
| risks.md | Risk register |
| notes.md | Open question resolutions, session notes |
| adrs/, plans/ | Formal ADRs / implementation plans (create when first needed) |
